UE 5.8 · 第一人称丧尸生存射击 · 关卡设计

贪婪
GREED

末日因人类对永生的贪婪而起——「永生药剂」临床失控引发尸变。玩家是末日拾荒者，核心机制「贪婪负担」：搜集的物资越多，移速与射速的负面效果越重；而最终 BOSS，会对高贪婪的玩家索取额外伤害。

机制与主题互证

「贪婪」不是贴在世界观上的标签，而是写进每一次按键的机制：拿，还是不拿——每件物资都立刻变成移速与机动的代价，而 BOSS 的「贪婪索取」技能让这笔账在关卡终点一次性清算。玩家在关卡里的每一步，都在为进 BOSS 房时的自己做出选择。

  • 轻装速通流：满机动风筝走位，放弃收益换生存
  • 贪婪搜刮流：高收益低机动，用走位压力换装备优势

关卡设计：灰烬高塔

当前关卡「灰烬高塔」是一座三层实验室 + 地下 BOSS 房的全封闭室内关卡，我独立完成从 LDD 设计文档、灰盒搭建到动线验证的全流程。

动线结构（全区域串联）

2F 出生区 → 主廊 → 房间1 → 楼梯↓ 1F 房间2 → 精英房①「肿胀巨尸」→ 电梯↑ → 3F 房间3 + 三侧屋 → 走廊桥 → 精英房②「腐蚀喷吐者」（掉落「电梯电源核心」）→ 大电梯↓ 26m → BOSS「守库巨兽」→ 金库撤离
  • 所有命名区域都在主路径上，不做支线化——关卡的每一米都被玩家走过
  • BOSS 房唯一入口是大型货运电梯：击败 3F 精英拿到电源核心才能启动，下降 26 米的 12 秒是一段刻意为之的压迫段落

单向门禁：让空间自己引导玩家

  • 出生点旁通往 1F 的电梯门、通往 3F 的东侧楼梯门均不可从 2F 侧打开——玩家被迫走完整个垂直循环，无法跳关
  • 东侧楼梯仅 3F 侧可开，构成 3F→2F 的单向撤回捷径
  • 设计意图：把「必须走完全程」从人为限制变成空间叙事——出生点被锁死本身就是关卡引导

贪婪值锚点

贪婪机制绑定在 6 个具体拾取点上，让抽象数值变成一次次可感知的赌博：

  • A 初始装备 = 第一笔贪婪值入门
  • E 房间2 物资堆 = 第一次真正的抉择
  • F 战后 AKM 必拿，但立刻加重负担
  • I 侧屋 = 贪婪值暴涨的诱惑点
  • J 走廊桥 = 高贪婪直接兑换成风险（移速慢、无掩体暴露）
  • M 落地前电梯口 = 最后的卸货权衡

光照反转：最深处最亮

  • 2F 冷白均匀 → 走廊半明半暗 → BOSS 房过曝纯白——刻意打破「越深越暗」的恐怖关卡惯式
  • 压抑感来自无菌般的纯净（药企「纯化舱」意象），而非黑暗
  • 电梯门开启的瞬间 = 光照与空间的双重反转，是整座塔的 Hook 时刻
  • BOSS 房空旷无掩体：风筝走位是唯一「掩体」，战斗压力直接由玩家此前的搜刮决策决定

实现状态

  • 239 件建造件全封闭灰盒：1m 网格稠密审计 + 射线复验全部 HIT，白名单外的洞口为零
  • 三座折返楼梯 + 两部电梯（G 电梯轿厢 + 滑门传送蓝图；L 大电梯 10 段折返坡道）立体动线全部可通行
  • 丧尸 AI 行为树（随机移动 / 发现玩家 / 追击至最后位置）、武器（AKM / SCAR）与拾取系统就绪
  • 36+ 盏动态点灯全 Movable，配合 Lumen 不烘焙

开发过程：文档驱动的关卡管线

  • LDD 设计文档先行：9 页成品（总览图 / 剖面图 / 流程图 / Note / Flow 表 / Hooks），美学、节奏、机制锚点全部成文后才动工
  • 数据驱动重建：权威建造清单（build_all.json：205 件建造件的名称 / 位置 / 尺寸 / 俯仰 / 材质）——场景损坏时可按清单精确重建，关卡即数据
  • 灰盒验证优先：封闭性 / 连通性 / 灯光节奏先于美术资产验证，几何确认后才进入道具与布光阶段
