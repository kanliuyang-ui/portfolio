明朝断案录MING DYNASTY CASE RECORDS

证据与口供之间，由你写下判词。

以“粮仓失窃案”为起点，勘查场景、搜集物证和文书，在公堂用证据挑战口供，最后用自己的中文文字提交判词。一个围绕推理过程与本地评分构建的离线断案原型。

比赛项目：腾讯云黑客松

01 / 玩家体验

怎么玩，为什么这样玩。

公开版本包含一个简体中文案件，将场景调查、证词核对与自由文本判词连成完整循环。

  1. 勘查场景
  2. 收集证据
  3. 核对口供
  4. 提交判词

02 / 设计重点

把主题做进机制里。

01

把调查落在具体场景里

点击仓库、街道与房间中的热点，取得物证与文书。线索不只是一段背景介绍，而是后续问询与判断可以使用的材料。

02

证据推动问询与新地点

完成对话可解锁后续地点和线索；公堂中提交证物，核对证词中的矛盾。调查和审问相互推动，而非两组互不相关的收集任务。

03

写下理由，而不只选择答案

判词由玩家自由输入中文文本，再获得本地确定性评分和反馈。交付对象是玩家组织出的判断，不只是从预设列表中选中一个名字。

03 / 项目画面

画面与设计相互对照。

04 / 真实迭代

从问题，到具体改变。

把交付收敛为可离线运行的案件

发现的问题

历史版本围绕独立评分服务与前端展开，运行条件和实际游戏体验分散。

做出的调整

Windows 游戏采用 C# 本地评分，当前案件不依赖云服务、API Key 或历史 Node 前端，让下载、调查和判词在同一离线流程中完成。

05 / 当前版本

itch.io · 免费 Windows 原型

itch.io 免费提供 Windows 离线原型。公开包包含“粮仓失窃案”一个案件，游戏内容与判词输入为简体中文。
